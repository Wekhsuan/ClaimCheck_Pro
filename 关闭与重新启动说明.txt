================================================================================
ClaimCheck Pro - 服务关闭与重新启动操作指引
================================================================================

一、如何关闭正在运行的 ClaimCheck Pro 服务
--------------------------------------------------------------------------------
1. 控制台优雅退出：
   - 切换到正在运行【ClaimCheck Pro】的命令行黑色终端窗口。
   - 在窗口内按下键盘快捷键：Ctrl + C
   - 终端提示“Terminate batch job (Y/N)?”时，输入 Y 并回车即可完全终止服务。

2. 直接关闭窗口：
   - 直接点击运行窗口右上角的关闭按钮（×），系统将立即释放端口并退出进程。

3. 后台进程强制关闭（若端口未释放）：
   - 在 PowerShell 中执行以下命令快速查询并终止 Streamlit 进程：
     Get-Process -Name python | Where-Object { $_.CommandLine -like "*streamlit*" } | Stop-Process -Force


二、如何重新启动 ClaimCheck Pro 服务
--------------------------------------------------------------------------------
1. 启动脚本运行（推荐）：
   - 双击项目根目录下的【start_claimcheck.bat】（纯英文脚本，杜绝 Windows CMD 编码乱码）。
   - 脚本将自动完成环境自检、依赖检查、端口智能冲突检测（8501被占时自动切8502），
     并自动调用默认浏览器打开系统首页。

2. 手动命令行启动（开发者模式）：
   - 打开 PowerShell 并定位到项目根目录 D:\ClaimCheck_Pro：
     cd D:\ClaimCheck_Pro
   - 运行专用虚拟环境启动命令：
     .\.venv\Scripts\python.exe -m streamlit run streamlit_app\app.py --server.address 127.0.0.1 --server.port 8501


三、常见端口与网络排查
--------------------------------------------------------------------------------
1. 端口占用自适应机制：
   - 启动脚本默认监听 8501 端口；若 8501 被系统其他程序占用，脚本会自动降级改用 8502，
     此时浏览器将自动访问 http://127.0.0.1:8502。

2. 浏览器未自动弹出：
   - 请手动在 Chrome、Edge 或其他现代浏览器地址栏输入：
     http://127.0.0.1:8501 (或 8502)

3. 零费用安全保障说明：
   - 本项目完全运行在本地隔离虚拟环境中，重启不会导致任何未经授权的外部计费。
   - 关闭后所有临时会话数据安全释放，报告已持久化保存在 output/ 目录中。
